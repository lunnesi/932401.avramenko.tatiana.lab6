# Лабораторная работа №6 — Веб-сервер на Node.js и Express, локализация API и PWA

## Описание проекта
Учебный веб-проект по дисциплине «Веб-технологии» (5 семестр), выполненный на **Node.js** и **Express**.

В рамках работы реализованы:
- запуск локального HTTP-сервера на порту `3000`;
- раздача статических файлов из директории `public`;
- REST/HTTP API-маршрут `/api/greet/:name` с валидацией параметра `:name` и поддержкой локализации через query-параметр `?lang=ru` (по умолчанию используется английский язык `en`);
- клиентский интерфейс (`index.html` и `about.html`) с единой таблицей стилей (`style.css`);
- функциональность **Progressive Web App (PWA)** с помощью манифеста (`manifest.json`) и Service Worker (`sw.js`) для кеширования ресурсов и работы в офлайн-режиме.

---

## Структура проекта

```text
lab6/
├── public/
│   ├── index.html      # Главная страница с формой запроса к API и регистрацией Service Worker
│   ├── about.html      # Страница «О себе» с информацией о разработчике и проекте
│   ├── style.css       # Общие стили оформления для страниц приложения
│   ├── manifest.json   # Манифест PWA (название, тема, параметры запуска приложения)
│   └── sw.js           # Service Worker для кеширования статики и офлайн-доступа
├── server.js           # Серверная логика на Express: статика, логирование, API и обработка ошибок
├── package.json        # Метаданные проекта и список зависимостей (Express)
├── package-lock.json   # Зафиксированные версии установленных пакетов
└── README.md           # Описание проекта и инструкция по запуску
```

## Назначение компонентов
Серверная часть (server.js)
- Раздача статических файлов: отдаёт содержимое папки public (/, /about.html, /style.css, /manifest.json, /sw.js).
- Логирование запросов: фиксирует поступающие HTTP-запросы в консоли сервера.
- Маршрут GET /api/greet/:name:
    -принимает имя пользователя в пути :name и проверяет его корректность (при некорректном значении возвращает статус 400);
    -считывает query-параметр lang (?lang=ru переключает язык приветствия на русский, по умолчанию используется en);
    -формирует и возвращает JSON-ответ в следующем формате:
{
  "message": "Привет, Татьяна!",
  "timestamp": "2026-11-24T16:48:00.000Z",
  "lang": "ru"
}
При языке по умолчанию (en):
{
  "message": "Hello, Tatyana!",
  "timestamp": "2026-11-24T16:48:00.000Z",
  "lang": "en"
}
     -Обработка несуществующих маршрутов: возвращает статус 404 при обращении к неизвестному пути.
## Клиентская часть и PWA (public/)
- index.html — предоставляет форму ввода имени, выбор языка (en / ru), кнопку отправки запроса методом fetch на /api/greet/:name?lang=..., блок вывода полученного JSON и регистрирует sw.js.
- about.html — содержит сведения об авторе и краткое описание лабораторной работы, использует общие стили из style.css и подключает манифест/Service Worker.
- style.css — отвечает за визуальное оформление контейнеров, типографику, формы, кнопки и блок вывода JSON на обеих страницах.
- manifest.json — описывает метаданные PWA для браузера и операционной системы.
- sw.js — перехватывает запросы, кеширует статические ресурсы приложения и обеспечивает их доступность при отсутствии подключения к сети.

## Установка и запуск

Перейдите в каталог проекта в терминале:

PowerShell
cd "D:\5 семестр\web-технологии\lab6"
Установите зависимости (если папка node_modules ещё не создана):

PowerShell
npm install
Запустите сервер:

PowerShell
node server.js
Откройте в браузере адрес:

Plaintext
http://localhost:3000
