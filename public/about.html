О проекте

В рамках данной лабораторной работы реализован веб-сервер на Node.js и Express. Сервер обрабатывает статические веб-страницы, поддерживает API с локализацией ответов (RU/EN), а также превращён в PWA с помощью манифеста и Service Worker для работы в офлайн-режиме.
